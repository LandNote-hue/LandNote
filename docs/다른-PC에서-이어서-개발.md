# 다른 PC에서 이어서 개발하기

지금 PC와 **같은 계정·같은 클라우드 매물**로 작업하는 방법입니다.

PC에 Supabase를 설치하거나 로컬 DB를 띄울 필요는 없습니다. 인증과 매물 클라우드는 이미 쓰는 Supabase 프로젝트에 붙습니다.

---

## 1. 이 PC에서 가져갈 것

복사할 폴더는 하나뿐입니다.

```
D:\중개업무\LandNote
```

이 폴더가 테스트(로컬 개발) 프로젝트 전체입니다. **반드시 `.env.local`을 포함**해서 복사하세요. 이 파일은 git에 올라가지 않습니다.

`.env.local` 안의 아래 두 값이, 지금 쓰는 Supabase에 붙는 키입니다.

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

로그인하면 클라우드 매물이 내려옵니다.

### 같이 가져가면 좋은 것

- 아직 git에 안 올린 로컬 수정 (목록 UI, 필터 등) — GitHub만 받으면 운영 코드만 오고 테스트 작업분은 빠집니다.
- 주소·지도용 키도 `.env.local`에 있습니다. (도로명 검색, vworld, 카카오맵 등)

### 가져가지 않아도 되는 것

| 경로 | 이유 |
|------|------|
| `node_modules` | 새 PC에서 `npm install` |
| `dist` | 빌드 결과물 |
| `D:\중개업무\LandNote-sale-all` 등 옆 폴더 | 운영 배포용 복사본 |

USB·NAS로 옮길 때 `node_modules`와 `dist`는 빼면 용량이 줄어듭니다.

### 폴더만으로는 안 넘어가는 것

브라우저 IndexedDB에만 있던 데이터(클라우드에 안 올라간 로컬 매물)는 폴더에 없습니다. 클라우드에 동기화된 매물·계정은 `.env.local`이 맞으면 로그인해서 다시 받습니다.

---

## 2. 새 PC에서 할 일

1. Node.js를 설치합니다. (LTS)
2. `LandNote` 폴더를 원하는 위치에 둡니다. `.env.local`이 루트에 있는지 확인합니다.
3. 그 폴더에서:

```bash
npm install
npm run dev:all
```

4. 브라우저에서 개발 서버 주소로 연 뒤, **지금과 같은 계정으로 로그인**합니다.

Vite 기본 주소는 보통 `http://localhost:5175` 입니다. (설정에 따라 다를 수 있습니다.)

`npm run dev`만 켜면 프론트만 뜹니다. 주소 조회(도로명·대장)까지 쓰려면 **`npm run dev:all`** (프론트 + BFF)이 필요합니다.

---

## 3. Supabase는 “켜 두어야” 하나

- 이 PC에 Supabase 프로그램을 실행할 필요는 없습니다.
- 인터넷이 되고, 쓰던 **클라우드 프로젝트**가 살아 있으면 됩니다.
- `.env.local`의 URL·anon 키가 그 프로젝트를 가리킵니다.

키가 비어 있으면 클라우드에 붙지 않습니다. 그때는 `VITE_AUTH_DEV_BYPASS=true`로 UI만 볼 수 있고, 실계정·실매물은 안 내려옵니다.

---

## 4. 보안

`.env.local`에는 API 키와 Supabase 키가 들어 있습니다.

- git에 커밋하지 마세요. (이미 `*.local`로 무시됩니다.)
- 공개 저장소·메신저에 붙여 넣지 마세요.
- USB로 옮긴 뒤에는 분실하지 않게 보관하세요.

키 이름만 보려면 저장소의 `.env.example`을 참고하면 됩니다. 실제 값은 `.env.local`에만 있습니다.
